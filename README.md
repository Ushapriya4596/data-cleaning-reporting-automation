# Data Cleaning & Reporting Automation

## Project Overview
This project demonstrates how Python can be used to clean sales data, handle missing and invalid values, standardize text, and generate automated reports and visualizations.

## Objectives
- Identify missing values and duplicate records.
- Standardize column names and text values.
- Handle missing and invalid sales values.
- Export a cleaned dataset.
- Generate a summary report and sales charts.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Project Files
- `Data_Cleaning_&_Reporting_Automation.ipynb` — Jupyter notebook containing the project code.
- `Data_Cleaning_Project.zip` — Archive containing the project output files.
- `cleaned_sales_data.csv` — Cleaned sales dataset.
- `cleaning_report.csv` — Summary of the cleaning process.
- `sales_by_region.png` — Sales visualization by region.
- `sales_by_product.png` — Sales distribution by product.

## Workflow
1. Load the original sales dataset.
2. Inspect missing values and duplicate records.
3. Standardize text and column names.
4. Handle missing and invalid sales values.
5. Export the cleaned dataset.
6. Generate a summary report and charts.

## How to Run
Open the notebook in Google Colab, run the cells in order, and review the generated CSV files and charts.

## Note
This project uses sample sales data for educational purposes.
